# BoardLab — контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

BoardLab — учебный многостраничный сайт магазина настольных игр. Пользователь может посмотреть подборку на главной странице, открыть каталог, изучить характеристики игры и заполнить форму заказа.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке: шапка, hero-блок, преимущества, популярные товары и подвал.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- добавлена единая адаптивная Bootstrap-навигация;
- создана страница каталога `catalog.html`;
- создана страница товара `product.html`;
- создана страница заказа `order.html`;
- использованы компоненты `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`;
- добавлены хлебные крошки и адаптивная таблица характеристик;
- файл `css/custom.css` дополняет Bootstrap минимальными стилями.

## Используемые технологии

- HTML5;
- CSS3;
- Bootstrap 5.3.8 через CDN;
- Git и GitHub.

## Структура проекта

```text
kr2-bootstrap-shop/
├── index.html       — главная страница
├── catalog.html     — каталог настольных игр
├── product.html     — страница выбранной игры
├── order.html       — форма заказа
├── css/
│   └── custom.css   — дополнительные стили
├── README.md        — описание проекта

```

## Запуск

Откройте `index.html` в браузере. Для работы интерактивных компонентов требуется доступ к CDN Bootstrap.

## Проверка

1. Откройте все четыре HTML-страницы и проверьте ссылки навигации.
2. На странице каталога откройте модальное окно кнопкой «Заказать».
3. На странице товара раскройте пункты accordion.
4. На странице заказа проверьте обязательные поля формы.
5. В DevTools проверьте ширины 375, 768, 1024 и 1440 пикселей.
